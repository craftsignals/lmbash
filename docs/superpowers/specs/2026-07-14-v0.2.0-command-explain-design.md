# lmbash v0.2.0 命令解释与风险提示设计

## 目标

在保留现有“生成、编辑、确认、执行”流程的前提下，帮助用户在执行前理解命令，并让中、高风险命令获得额外可见提示。v0.2.0 不引入本地规则引擎，也不改变任何命令的执行权限或确认语义。

## 范围

- 生成或编辑出新命令后，自动调用当前配置的 LLM 进行风险评估。
- 风险等级为“低”时不显示额外内容；“中”或“高”时显示等级与简短原因。
- 主操作菜单新增 `x`（简洁解释）。
- 用户看过简洁解释后，主操作菜单新增 `xx`（详细解释）。
- 风险评估与解释均复用现有 provider、模型、代理和错误处理。

## 非目标

- 不使用本地命令规则、关键词白名单或风险拦截。
- 不阻止任何命令执行；`y` 仍按当前语义确认执行。
- 不新增配置项、依赖、远程存储或命令历史数据库。
- 不缓存解释结果；每次 `x` 或 `xx` 都是一次独立 LLM 请求。

## 用户交互

### 命令生成和风险提示

每次 provider 成功返回新命令后（首次生成或编辑完成），CLI 自动发起风险评估。风险评估返回固定的等级和原因：`low`、`medium` 或 `high`。

- `low`：不显示风险信息。
- `medium`、`high`：在生成命令块下方显示本地化等级与一行原因。
- 请求失败：显示“风险评估不可用”，但继续显示命令与正常操作菜单。

风险提示只供用户审阅。无论评估结果为何，用户输入 `y` 都继续使用当前执行路径。

### 操作菜单

默认菜单为：

```text
Action? [y] execute, [e] edit, [x] explain, [N] cancel
```

输入 `x` 后，CLI 对当前命令请求简洁解释，显示结果，再回到菜单。简洁解释成功显示过至少一次后，菜单变为：

```text
Action? [y] execute, [e] edit, [x] explain, [xx] explain more, [N] cancel
```

输入 `xx` 后，CLI 对当前命令请求详细解释，显示结果，再回到菜单。若尚未成功获得简洁解释就输入 `xx`，CLI 提示先使用 `x`，不调用模型。

编辑产生新命令后，CLI 清除“已显示简洁解释”的状态，重新进行风险评估，并恢复默认菜单。

### 解释内容

简洁解释固定覆盖：

1. 命令整体目的；
2. 关键命令、选项或 shell 结构；
3. 主要影响或注意事项。

详细解释按 shell 结构说明每段子命令、管道、重定向、变量、命令替换及重要参数。两种解释均不得执行、修改或重新生成原命令。

## 架构

在 `lmbash.providers` 中新增与既有客户端协议兼容的分析请求接口，供 OpenAI-compatible 和 Claude-compatible provider 复用各自现有 HTTP 传输逻辑。该接口接受一个明确的提示词并返回文本结果。

在 `lmbash.cli` 中新增三个纯函数：构建风险评估提示词、构建简洁解释提示词、构建详细解释提示词。CLI 循环持有当前命令、当前风险提示和 `brief_explanation_seen` 状态；它负责显示和状态转换，但不解析 LLM 的自然语言解释。

风险评估响应使用受限格式，以稳定提取等级与原因：第一行必须是 `low`、`medium` 或 `high`，后续文本为原因。响应为空、等级无效或请求失败时统一按“风险评估不可用”处理，不将其误报为高风险。

## 错误处理

- 风险评估失败、格式无效或网络异常：打印非阻塞状态，继续当前菜单。
- `x` 或 `xx` 请求失败：打印现有风格的错误信息，保留当前命令和菜单；不改变 `brief_explanation_seen` 状态。
- 用户取消、编辑或执行：沿用现有退出码、执行输出和 shell history 行为。

## 测试与验收

单元测试必须覆盖：

- 三种提示词包含命令和所需输出格式；
- `low` 风险不显示，`medium` 与 `high` 显示原因；
- 风险评估失败或返回无效等级时正常进入操作菜单；
- `x` 显示简洁解释并启用 `xx`；
- `xx` 在未执行 `x` 时不请求 provider，执行 `x` 后请求详细解释；
- 编辑后清除 `xx` 可用状态并重新评估风险；
- 风险或解释请求失败后仍能编辑、执行或取消；
- 已有 provider、执行、配置及 Bash/Zsh history 测试继续通过。

验收标准：用户能在生成命令后看到中、高风险提示；能用 `x` 获得简洁解释、再用 `xx` 获得详细解释；这些功能失败时不会阻碍用户按现有方式执行、编辑或取消命令。
